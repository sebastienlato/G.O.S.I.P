# Product definition

Interactive world map + equally useful event list; selectable layers for environment, physical activity, geopolitics, digital infrastructure, and major developments. Event details include original source link, occurrence/publication/retrieval times, status, freshness, coverage, corrections where known. Filtering by category, geography and time. Responsive and keyboard accessible. No account required.

**Phase 0:** attractive usable map/list/details prototype populated by invented demo events **visibly labeled SIMULATED**. Do not use fictional current conflict claims about real people. Success means owner can run and explore it locally.
