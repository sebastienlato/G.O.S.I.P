# Architecture — Phase 2

A static React + TypeScript application. `App.tsx` owns selected-event context separately from the detail dialog and explicit map-focus requests. One filtered array drives map/feed. `src/state/explorer.ts` validates/serializes source, search, layers, window, view and map preference; `useExplorerFilters.ts` synchronizes history. No data/selection/camera are encoded in links.

`src/data/events.ts` uses an `is_demo` discriminated union. The demo parser still accepts only labeled simulations, preserving its 18 fixtures and fixed clock. Earthquakes retain provider IDs/network/code, validated source links, nullable estimates/review/update, occurrence, retrieval and feed-generation times. `filterEvents` accepts an explicit reference clock; the app supplies current device time at minute resolution for USGS and the fixed snapshot for demo.

`src/data/usgs.ts` exposes one fixed endpoint and a bounded parser/provider. Streaming enforces 2 MB, the envelope allows at most 2,000 records, and a 12-second abort covers fetch/body reading. Bad records are counted; invalid envelopes/all-invalid observations fail. Non-earthquake records are explicitly excluded. One in-flight request is shared; attempts are throttled for 60 seconds with rate-limit backoff. No polling or persistent storage. `useEarthquakes.ts` retains the current snapshot/error in memory and ticks only the UI clock/cooldown. Source switches do not refetch an already loaded snapshot. Failed refreshes preserve data with a stale warning; successful refresh replaces the snapshot, including corrections/removals. No historical correction ledger.

`FeedSource.tsx` owns the visible source choice/status, provenance, limits and manual refresh/fallback controls. Fixtures and real observations never share an array or automatic fallback. Detail dialogs use conditional provenance and measurement fields, with focus return. Marker labels/badges reflect their data source. Source choice defaults to demo to preserve offline startup; explicit `source=usgs` links load observations.

`WorldMap.tsx` still loads MapLibre JS/CSS/worker only in interactive mode, uses local Natural Earth geometry, handles resize/lifecycle cleanup and WebGL/network fallback to SVG, preserves selection, and supports explicit regional focus and cooperative touch gestures. List/static entry avoids all interactive-map downloads. No clustering; the full feed remains the way to inspect overlapping markers. Mobile feed scrolls with the page.

Vite builds `dist/`; Vitest tests parser/provider/filter/URL boundaries; Playwright tests deterministic production desktop/mobile behavior and injected failures. No credentials, auth, backend, external tiles/fonts, analytics, deployment or service worker. USGS is the only external runtime data request, only when selected. Review source-specific permissions in `DATA_POLICY.md`; Phase 3 owns persistence and additional refresh resilience under the $0 mandate.
