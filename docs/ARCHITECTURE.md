# Architecture — Phase 14

React/TypeScript/Vite static explorer, bundled Natural Earth geography and lazy MapLibre. Independent USGS, EONET, DWD and available FIRMS checkboxes feed one filtered array for map/list/selection/details. All available live layers default on; simulation modes remain separate. Validated `live` subsets include none; explicit legacy `source=usgs` stays USGS-only. Category/search/place/window/view state remains shareable; selection clears when filtered out. Internal `source: 'usgs'` remains the live-mode compatibility name.

`App.tsx` owns composition. `EventFeed`/`EventCard`, `WorldMap`/`MapLegend`, source-specific detail bodies, `AboutDialog` and `FeedSource.tsx` render it. `encoding.ts` owns marker size/colour/fade/glyph. The desktop control rail stays one row with a category disclosure; phones use two-column layer toggles and wrapped controls. See DESIGN.md.

`ingest/source.ts` runs fixed identified requests with a 12-second timeout, streaming byte bounds and no immediate retries. It independently validates each source, falls back to revalidated same-origin last-good data and preserves original times. Fixed allowlisted failure codes identify stages without echoing raw provider responses, arbitrary exceptions or credential-bearing URLs. Failure without usable data publishes failed/null, never successful empty. `ingest/run.mjs` emits ignored source publications plus mirrored `health.json`; no data commits or history archive.

- USGS: M2.5+ week, 2 MB/2,000 records; occurrence time, provider generation/revision, nonempty/nonstale ingestion. Existing compact validation preserved.
- EONET: storms/volcanoes, open+closed 30-day query, 201-entry sentinel/200 maximum, 500 KB. Latest geometry date, null magnitude/unit/time fields preserved; valid polygons feed-only. No invented occurrence/publication/update/generation. Flood/landslide integration remains deferred.
- DWD: exact JSONP wrapper parsed as JSON, never executed; 600 KB/1,500 warnings/600 districts. German headlines, descriptions, instructions, level, altitude nulls and forward validity intervals. Known expiry removes a record; unknown coastal end remains null/source-listed. Feed time, retrieval and pipeline attempt stay distinct. No supplied coordinates means feed-only, no centroid/geocoding. Preliminary information excluded.
- FIRMS: owner-created Actions secret only in ingestion. Fixed NOAA-20 VIIRS one-day query for a North American sector (170°W–50°W, 15°N–75°N), UTC date two days back. Initial global query exceeded the 60,000-row cap; scope narrowed rather than raising limits. 8 MB/60,000-row input and 200 KB/2,500-cell publication. Only product/area/day and 2° cell counts survive; no raw detection coordinates/times/key. Always ≥24 hours delayed; backward interval overlap, generation/publication/update unknown, counts are not distinct fires. Default 24-hour view excludes those delayed days; 3/7 days includes them.

`usePublished` consumes atomic embedded health/data from same-origin JSON only. Each source has independent loading/error/stale state, 15-minute checks while enabled/visible/online and one-minute manual cooldown. Failed fetch or failed/null publication retains page memory with stale status. Stale at 45 minutes from older generation/retrieval, or failure; EONET/FIRMS use retrieval when generation is unknown. Recent retrieval cannot prove recent curation/observation. The real device clock moves even with all layers off. No browser-provider data calls, localStorage or invented fallback.

Vite exposes only a boolean derived by decoding the ingested/retained FIRMS publication, never the key. `GOSIP_TEST_FIRMS=1` enables that UI for mocked browser tests. Without a usable fire snapshot the layer remains coming; with one, legacy web fire-demo links redirect to FIRMS at 72 hours and the fire lab option disappears. Native source parsing/fixtures remain unchanged and native development stays paused. Web seismic/coastal-weather/volcano examples remain retired. Other lab layers are separate. Existing NWS point forecasts remain loopback-only, not alerts.

Official pinned Pages Actions uses relevant main push/manual/15-minute UTC scheduling, public-repo/owner-$0 guard, standard Linux, no cache and a 4 MB whole-site cap locally and in CI. Artifact accumulation check, one-day retention and current-run cleanup remain. No-payment-method confirmation and ZERO_COST_STORAGE_CONFIRMED persist; payment changes require a $0 stop-usage budget. Accept delay/drop/inactivity/stale data instead of paid upgrades. DATA_POLICY records rights/coverage; BETA_READINESS and PROJECT_STATE record actual release evidence.
