# Architecture — Phase 12

React/TypeScript/Vite static explorer with a local Natural Earth map and lazy MapLibre. One filtered event array drives map/feed, selection and details. URLs encode validated filters, not records or camera state. USGS is default; real windows use device time. Simulations require an explicit source in the separate lab; the replaced seismic example is hidden from web.

`ingest/usgs.ts` fetches a fixed USGS M2.5+ week feed once per run (12-second timeout, 2 MB, 2,000 records). Existing `parseUSGS` validates source parameters and rejects unsafe event links, invalid timestamps/geometry and malformed envelopes. The compact encoder removes unneeded provider fields; the decoder regenerates display text through the same validator. `ingest/run.mjs` uses Vite's existing TS loader, writes ignored `public/data/usgs.json` and `health.json`; no new runtime dependency.

Each publication embeds health beside the snapshot: source, attempt time, original fetched/generated times, count, status and safe error. A standalone health index mirrors it. The browser reads the single combined file to avoid mixing health/data from different CDN generations. On ingestion failure, fetch and revalidate the last published snapshot, retain original timestamps and mark stale. If that also fails, publish failed status and null data. Empty/all-invalid/stale provider feeds never count as success. Old retained snapshots remain bounded and labeled, but the real clock naturally removes events outside the selected past-week window. No archive yet.

`useEarthquakes` reads only same-origin JSON with a streamed byte limit and 12-second timeout. Initial load plus 15-minute checks while visible/online; manual refresh has a one-minute cooldown. No provider calls or localStorage writes. Failed browser fetch retains memory data; failed pipeline health is visible. A local clock marks data stale after 45 minutes from older generation/retrieval, even if the workflow never runs again. Legacy provider/cache/store modules remain tested utilities, unused by this hook. NWS direct transport remains loopback-only development.

`.github/workflows/pages.yml` builds/tests/ingests and uses official pinned configure/upload/deploy Pages actions. Main pushes, manual dispatch and UTC minutes 7/22/37/52; serialized concurrency, standard public runners, job timeouts, scoped permissions, no dependency cache. Snapshot data is packaged in the site artifact, never committed. 4 MB site budget, repository artifact accumulation guard, one-day expiry and this-run artifact cleanup. Public visibility and owner-confirmed storage safeguard are prerequisites. No workflow can guarantee schedule timing or CDN freshness.

Native SwiftUI remains paused, bundled/offline, with historical simulation contracts. See IOS.md. Native links that omit a source now resolve to live USGS on web; simulation links should explicitly specify their source. No native live parity is claimed. Historical web fixture contracts and source reviews remain in PHASES_0_11_HISTORY.md and DATA_POLICY.md.
