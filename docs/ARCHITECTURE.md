# Architecture — current web with historical implementation notes

Phase 21: same-origin release polling (2 KB, minute checks, visible/online only, retained stamp on failure) exposes published build age independently of active layers and history. Shared cadence.ts defines provider descriptions, safety delays, source request targets and stale thresholds. Ingestion reuses revalidated not-due snapshots/health exactly; serialized workflow guards schedule/external runs on release age and source attempt age. Push/manual only bypass publication gate. Worker is local trigger-only code pending owner configuration; no browser/ingestion data connection to Cloudflare. Compatible feed kinds rank within time-ordered kind slots to avoid a non-transitive mixed comparator. Archive new additions are capped at 4 MB; legacy reads stay bounded to 7.1 MB solely for natural-expiry migration.

Roadmap 3.0 planning increment: `parsePublicFilters` defaults missing/invalid hours to Auto, while `serializePublicFilters` preserves explicit 24h links. Legacy parser/serializer numeric defaults remain for frozen native compatibility. `filterEvents` resolves fixed source-specific real-clock windows through `defaultWindowHours`; no snapshot-age anchoring or stale-data revival. App applies 24h-before-capture for Auto History; current subsets/windows persist. Explicit common windows keep their existing semantics. Plain Layer windows disclosure explains the different periods.

Phase 20 supersedes the simulation/development routes mentioned below: App renders reviewed current/history snapshots only. `parsePublicFilters` normalizes old source links before first render; unavailable aviation/NWS and unavailable replaced layers retain shareable coming states. The legacy parser remains only for fixture/native compatibility tests. Fixture arrays/JSON/documents live under `tests/fixtures/legacy/`; a production module-graph guard and Pages file guard reject them. No direct-provider NWS CSP permission. Native resources remain frozen.

React/TypeScript/Vite static explorer, bundled Natural Earth geography and lazy CesiumJS globe. Independent USGS, EONET, DWD, Global Voices reports and available FIRMS checkboxes feed one filtered array for map/list/selection/details. DWD defaults off; the other connected layers default on; simulation modes remain separate. Validated `live` subsets include none; explicit legacy `source=usgs` stays USGS-only. Category/search/place/window/view state remains shareable; selection clears when filtered out. Internal `source: 'usgs'` remains the live-mode compatibility name.

`App.tsx` owns composition. `EventFeed`/`EventCard`, `WorldMap`/`MapLegend`, source-specific detail bodies, `AboutDialog` and `FeedSource.tsx` render it. The feed renders 50 records per page; all records still participate in counts, search, filters and the map. Map selection reveals the corresponding page. `encoding.ts` owns marker size/colour/fade/glyph. The desktop control rail stays one row with a category disclosure; phones use two-column layer toggles and wrapped controls. See DESIGN.md.

`ingest/source.ts` runs fixed identified requests with a 12-second timeout, streaming byte bounds and no immediate retries. It independently validates each source, falls back to revalidated same-origin last-good data and preserves original times. Fixed allowlisted failure codes identify stages without echoing raw provider responses, arbitrary exceptions or credential-bearing URLs. Failure without usable data publishes failed/null, never successful empty. `ingest/run.mjs` emits ignored source publications plus mirrored `health.json`; no data commits. Phase 19 adds the bounded published history described below.

- USGS: M2.5+ week, 2 MB/2,000 records; occurrence time, provider generation/revision, nonempty/nonstale ingestion. Existing compact validation preserved.
- EONET: storms/volcanoes, open+closed 30-day query, 201-entry sentinel/200 maximum, 500 KB. Latest geometry date, null magnitude/unit/time fields preserved; valid polygons feed-only. No invented occurrence/publication/update/generation. Flood/landslide integration remains deferred.
- DWD: exact JSONP wrapper parsed as JSON, never executed; 600 KB/1,500 warnings/600 districts. German headlines, descriptions, instructions, level, altitude nulls and forward validity intervals. Known expiry removes a record; unknown coastal end remains null/source-listed. Feed time, retrieval and pipeline attempt stay distinct. No supplied coordinates means feed-only, no centroid/geocoding. Preliminary information excluded.
- FIRMS: owner-created Actions secret only; fixed global NOAA-20 VIIRS latest two UTC dates. Stream-validate 64 MB/500,000 rows, filter preceding 24 hours, aggregate into 2° cells. Only interval/product/area and cell counts survive; published 200 KB/2,500 cells. No additional delay, precise positions/times, distinct-fire claim or provider generation time. Reject old regional publications during migration rather than label them global.
- Global Voices: fixed English-edition RSS, identified 12-second/1 MB request; safe XML extraction ≤40 entries. Publish ≤100 KB of headline/byline/canonical link/publication metadata, past 7 days and ≥24-hour safety delay. No article/media copies, AI or map location. Null occurrence/update/generation; independent same-origin transport and last-good retention. One URL per card, never corroboration grouping. Report simulation retired; legacy report URLs open real 3-day news.

`usePublished` consumes atomic embedded health/data from same-origin JSON only. Each source has independent loading/error/stale state, 15-minute checks while enabled/visible/online and one-minute manual cooldown. Failed fetch or failed/null publication retains page memory with stale status. Stale at 45 minutes from older generation/retrieval, or failure; EONET/FIRMS use retrieval when generation is unknown. Recent retrieval cannot prove recent curation/observation. The real device clock moves even with all layers off. No browser-provider data calls, localStorage or invented fallback.

Vite exposes only a boolean derived by decoding the ingested/retained FIRMS publication, never the key. `GOSIP_TEST_FIRMS=1` enables that UI for mocked browser tests. Without a usable fire snapshot the layer remains coming; with one, legacy web fire-demo links redirect to FIRMS at 72 hours and the fire lab option disappears. Native source parsing/fixtures remain unchanged and native development stays paused. Web seismic/coastal-weather/volcano examples remain retired. Other lab layers are separate. Existing NWS point forecasts remain loopback-only, not alerts.

Official pinned Pages Actions uses relevant main push/manual/15-minute UTC scheduling, public-repo/owner-$0 guard, standard Linux, no cache and a 25 MB whole-site cap (D52, was 4 MB) locally and in CI. Artifact accumulation check, one-day retention and current-run cleanup remain. No-payment-method confirmation and ZERO_COST_STORAGE_CONFIRMED persist; payment changes require a $0 stop-usage budget. Accept delay/drop/inactivity/stale data instead of paid upgrades. DATA_POLICY records rights/coverage; BETA_READINESS and PROJECT_STATE record actual release evidence.

Globe (D52/D53): `WorldMap.tsx` lazy-loads `@cesium/engine` (not the widgets bundle) with runtime assets from `public/cesium/` (copied by `scripts/copy-cesium.mjs`, gitignored). Imagery layers come from NASA GIBS/Cesium ion in the browser; data never does. Points are DOM markers projected in `scene.postRender`; FIRMS cells render as a pickable smooth heat imagery layer. `App.tsx` lays out the console: banner, masthead, `.globe-area`, `.left-stack` (controls + reference panels) and `.panel-feed`. The optional `VITE_CESIUM_ION_TOKEN` comes from the `CESIUM_ION_TOKEN` Actions variable at build time.



Phase 16: `ingest/ooni.ts` requests only country aggregate web-connectivity counters for the UTC day ending ≥24 hours ago; `src/data/ooni.ts` validates and publishes totals ≥1,000 (100 KB/250 rows), discarding outcome counters. Empty source results fail; valid all-suppressed results retain explicit coverage. Same independent health/last-good and page-memory rules apply. `__OONI_AVAILABLE__` derives from a decoded snapshot at build time; without one the layer stays coming. Digital fixtures retire permanently from the web; legacy links migrate to OONI/3 days (all-off/coming if unavailable). Country context is static Natural Earth label geography rounded to whole degrees, unknown anchors null; never probe location. Network icon/blue hue follow D55; adapted OONI data includes its separate CC BY-NC-SA notice in every snapshot. No workflow registration/cadence, browser-data CSP, archive, account or billing change.

Phase 17: `ingest/launches.ts` selects bounded LL2 2.3.0 upcoming launch metadata; `src/data/launches.ts` validates compact rows, credit and independent mirrored health. At most 20 source entries, 500 KB runner input/100 KB publication, one identified request/run. `__LAUNCHES_AVAILABLE__` enables Space only with a decoded current/retained snapshot. NET precision determines a forward interval; unknown time is explicitly source-listed across windows. Only planned selected mission types; fixed sites rounded to 1° or feed-only. Shared rocket encoding, globe/feed/details/status; legacy space-demo migrates to seven-day real space. Source publication/generation/occurrence unknown, catalog update distinct. No browser provider calls, trajectory/orbit model, new backend/archive, native changes or workflow changes.

Phase 18: `ingest/maritime.ts` makes one 50 KB/70-row query to the public IMF PortWatch statistics service. Fixed five gateways and UTC range 14-to-4 days ago; latest returned day must cover every port. Only ≥20 totals aggregated in three 10° regions and rounded down to tens reach `maritime.json` (30 KB bound). No individual AIS records or geometry requested. `src/data/maritime.ts` revalidates delay, ranges, fields, credit and health; source generation remains null. `__MARITIME_AVAILABLE__` derives from valid current/retained snapshots. Smooth cyan layer uses the shared heat renderer with a separate palette and 10° picking, feed-accessible selection and original dates. Retired maritime lab migrates to seven-day maritime view; aviation stays separate/native unchanged. No workflow/CSP/backend/archive change.


Phase 19: `ingest/archive.ts` first restores same-origin `data/history.json`, then at most once per UTC day captures the already-public USGS/EONET publications between two matching release-stamp reads, requiring mirrored source health. One ≤7.1 MB archive carries ≤7 daily samples; every source ≤500 KB and revalidated using its original parser. Capture failure retains immutable prior samples; lost prior archive records a new continuity boundary. Runner/browser both prune older than seven real-clock days; an interrupted pipeline can leave expired raw JSON on Pages until a successful deployment. Nothing writes data to git or durable Actions storage. `useArchive` loads lazily in History mode, polls every 15 minutes while visible, and keeps page memory on fetch/failed-empty responses. `history=latest` resolves to an exact capture timestamp for share/reload; missing or expired timestamps show no records. App uses only captured sources in history, capture time as filter reference, source timestamps for event semantics, original health at capture, and independent saved current-layer subsets. Current mode/source safety contracts remain unchanged.
