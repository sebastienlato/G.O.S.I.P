# Architecture — Phase 13

React/TypeScript/Vite static explorer with local Natural Earth geography and lazy MapLibre. Independent live source checkboxes feed one filtered array for map/list/selection/details. USGS and NASA EONET are default; simulations use separate source modes. Selection clears when filtered out. Live `live=usgs,eonet` subsets (including empty), category `layers`, search/place/window/view are validated URL state. Explicit legacy `source=usgs` normalizes to `live=usgs`; simulation URLs discard live state. Internal `source: 'usgs'` remains the compatibility name for live mode.

`ingest/source.ts` is the shared bounded adapter runner: fixed provider and last-good URLs, 12-second timeout, streamed byte limit, identification, no immediate retry, independent safe health. `usgs.ts` preserves M2.5+ week parsing/compact contract (2 MB/2,000 records), rejects empty/stale observations. `eonet.ts` uses `src/data/eonet.ts`: storms/volcanoes, open+closed 30-day request, 201-entry sentinel, 200 entries/500 KB. Input shape, IDs, text, dates, categories, magnitude nulls, reference URLs and geometry are validated. Latest geometry only is published; valid polygons stay feed-only, with no inferred centroid. Descriptions/imagery/third-party reports are not republished.

`ingest/run.mjs` loads both adapters via Vite's existing TS loader and writes ignored `public/data/{usgs,eonet}.json` plus mirrored `health.json`. Each source publication embeds matching health and data; the browser reads that atomic file, never joins separate health/data generations. Sources may have independent update times. Provider failure revalidates the last published source snapshot, retaining original times; unavailable fallback publishes failed/null. EONET permits a structurally valid empty catalog, visibly distinguished from failure; USGS does not. No data commits or history archive.

`usePublished` in `useEarthquakes.ts` shares same-origin-only bounded browser transport, independent source cooldown/loading/error/stale state, initial load and 15-minute polling while enabled/visible/online. Manual refresh has a one-minute cooldown. A failed fetch or failed/null publication retains page-memory records, with stale status. No localStorage or direct provider fetch. Staleness is 45 minutes from original generation/retrieval for USGS and retrieval for EONET, or any failure. EONET has no feed-generation time: a recent retrieval cannot prove recent curation. The real device clock keeps moving even with all live layers disabled.

USGS uses occurrence dates and revised observation parameters. EONET uses latest dated geometry, retains approximate open/closed dates, and leaves occurrence/publication/update unknown. Card/detail/marker labels distinguish observation from curated hazard metadata; references are navigation only and never fetched/proxied. No implied cause, impact or cross-source corroboration. Older entries disappear from the chosen window naturally; stale data never gets new source times.

The pinned official Pages Actions workflow remains unchanged: relevant main push/manual/15-minute UTC schedule, standard public Linux runner, scoped permissions/timeouts, no dependency cache, 4 MB whole-site cap, artifact accumulation guard, one-day retention/current-run cleanup. Owner-confirmed no payment method and ZERO_COST_STORAGE_CONFIRMED are prerequisites; a payment-setting change requires $0 stop-usage budget. Accept interruption rather than pay. No schedule/CDN freshness guarantee.

Native SwiftUI remains paused and unchanged. Web hides replaced seismic/coastal-weather/volcano simulations; fixtures remain for tests/native and remaining lab sources stay explicitly separate. Local NWS point forecasts remain loopback-only, not public alerts. See DATA_POLICY and BETA_READINESS for scope and release evidence.
